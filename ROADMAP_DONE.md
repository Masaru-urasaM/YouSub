## Completed Phases

### Phase 1: Extension Foundation — Manifest V3 + Folder Structure
**Status**: DONE (2026-04-03)
**Summary**: Created valid Manifest V3 Chrome extension with the full folder structure. Initialized `manifest.json`, `main.js`, `overlay.css`, `service-worker.js`, popup HTML/CSS/JS, icons, tests, and logs directories. Handled basic `.gitignore`. Extension parsed successfully in Chrome with no errors.

### Phase 2: Design Decisions — Finalize Technical Approach
**Status**: DONE (2026-04-03)
**Summary**: Resolved and documented four architectural choices: 1) Inject `<script>` into Main world for subtitle interception, 2) Lingva API for initial MVP translation with LLM transition later, 3) Bulk translation strategy to translate all chunks upfront, 4) Inject the UI overlay into `#movie_player` for native fullscreen support.

### Phase 3: Content Script — YouTube Page Detection + SPA Navigation
**Status**: DONE (2026-04-03)
**Summary**: Created `page-detector.js` with IIFE + `window.YouSub.PageDetector` namespace. Handles SPA navigation via `yt-navigate-finish` event, detects initial page load, extracts video IDs, tracks `currentVideoId` to distinguish real video changes from URL noise. Updated `main.js` to wire up enter/leave callbacks. Updated `manifest.json` load order: `constants.js` → `page-detector.js` → `main.js`.

### Phase 4: Video Player Detection + Binding
**Status**: DONE (2026-04-03)
**Summary**: Created `video-binder.js` with IIFE + `window.YouSub.VideoBinder` namespace. Uses 3-selector cascade (`video.html5-main-video`, `#movie_player video`, `video`) to find the `<video>` element. Falls back to `MutationObserver` if not immediately available, with a 10-second timeout guard. `unbind()` cleanly disconnects observer, clears timeout, and nulls references to prevent memory leaks. `main.js` updated to call `bind()` on enter and `unbind()` on leave.

### Phase 5: Subtitle Track Discovery — Extract Available Tracks
**Status**: DONE (2026-04-03)
**Summary**: Implemented `subtitle-extractor.js` using MAIN world script injection. It extracts `ytInitialPlayerResponse.captions` and passes it back to the ISOLATED world via `window.postMessage` with a secure `YOUSUB_CAPTION_TRACKS` type. It properly handles edge cases (missing data, no captions) and normalizes output into a cleaner `{ languageCode, languageName, isAutoGenerated, baseUrl }` JSON format. `main.js` was updated to trigger extraction immediately after the video element binds.

### Phase 6: Subtitle Fetching + Parsing — Download and Parse timedtext
**Status**: DONE (2026-04-03)
**Summary**: Created `subtitle-parser.js` to handle YouTube's timedtext. To resolve 0-byte fetch issues caused by Manifest V3 CSP/CORS, a background fetch proxy was implemented in `service-worker.js`. The parser successfully fetches primary (JSON3) and fallback (XML) formats. Added `selectBestTrack` in `main.js` to automatically prioritize Vietnamese (Manual/Auto) then English Manual tracks. Verified successful parsing and logging of subtitle entries.

### Phase 7: Translation API Client — Setup and Configuration
**Status**: DONE (2026-04-03)
**Summary**: Created `translator.js` ES module using Lingva Translate API (Decision 2). Implements bulk-chunked translation: texts joined with `\n###YOUSUB###\n` delimiter, chunked to ≤1500 chars per URL, one API call per chunk. On split mismatch or API error, falls back to per-entry individual translation. On individual failure, returns original text. Added `YOUSUB_TRANSLATE_REQUEST` handler to `service-worker.js` (imports translator as ES module). Added `requestTranslation()` in `main.js` to wire parse → translate → `YS._lastSubtitles`. Added `YS.MSG` message type constants to `constants.js`. Full pipeline: detect → bind → extract → parse → translate → store.

### Phase 12: Popup UI & Transcript DOM Scraping Migration
**Status**: DONE (2026-04-03)
**Summary**: Successfully shifted from API fetch to a Transcript DOM Scraping mechanism in `main-world-extractor.js`. The extractor opens the native YouTube Transcript sidebar, parses `transcript-segment-view-model` segments to bypass Bot/CORS restrictions, and cleans up after. Generated `popup.html`, `popup.js`, and `popup.css` + custom extension icon to act as a user trigger (`YOUSUB_START_EXTRACTION`). This allows extracting explicitly on user command and setting target translation language dynamically. Background Service worker was also updated to use ES static imports per Manifest V3 restrictions.
